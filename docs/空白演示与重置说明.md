## 一次演示的建议顺序

1. 用 Taylor 登录，在健康资料填写出生日期及自己准备演示的基础信息。
2. 在报告与病历中点击医院同步，导入 8 份公共 PDF；检查分类、英文报告名称和全文检索。
3. 打开待核对内容，确认选中的指标与健康史。未确认内容不会直接进入健康事实。
4. 查看身体指标的趋势、明细和 PDF 来源，再查看独立的健康建议；需要 AI 分析时明确同意云端发送。
5. 演示选医生预约、按范围授权、双方 PDF 查看、撤销及操作记录。
6. 开启社区并加入圈子；用另一浏览器登录 Alex 或 Jamie，演示交友与私聊。
7. 需要重来时，打开 **Account and security → Reset my demo data / 账户与安全 → 重置我的演示数据**，确认后回到空白首页。

## 重置会清什么

按钮只在专用演示环境出现，只对当前登录账号操作，不删除数据库文件或登录账号。

- 清除个人健康史及修订、报告附件与全文索引、OCR 候选、医院导入及去重记录、指标和来源、更正及提醒历史。
- 清除 AI 结果和发送同意、共享授权与访问记录、预约、个人提醒、通知及操作历史；已预约名额会释放。
- 清空联系电话和出生日期；保留姓名、邮箱、密码、当前登录会话、语言及通知偏好、社区设置与昵称。
- 清除本人的练习发言、评论、点赞、非原始圈子加入、举报和主动屏蔽；保留精确识别的原始示例帖子、评论、赞和成员记录。
- 清除涉及本人的好友关系与整段私聊。因此对方也无法继续查看该段会话；无关会话及其他账号的健康资料不受影响。弹窗会在确认前说明。
- 保留 8 份公共医院 PDF、医生及机构目录、圈子介绍和原始社区内容。重新同步会导入 8 份报告，而不会被旧去重记录挡住。

操作在一个数据库事务内完成，失败会回滚。正在进行的 AI 分析在重置后不能把旧建议写回。重置后的个人数据无法在网站内撤销；本次批量整理现有演示账号前另行做了完整备份。

登录行为产生的新安全记录属于正常运行，不代表健康数据没有清空。共享的原始 PDF 样本和社区内容属于公共演示素材，也不应随个人重置删除。

## 英文界面与报告名字

已补齐共享范围摘要、共享内容预览、字段说明、审计详情、识别结果提示等固定文案的语言转换。8 份医院样本采用正式英文标题和文件名，中文模式可显示相应中文标题。重建样本的脚本不会重新覆盖为旧中文元数据。

只有系统能明确识别的原始样本字段才使用提供的双语名称。用户自己输入的病史、笔记、报告标题及上传文件名保留原文，不会为了界面语言而改写真实内容；PDF 原件不翻译。旧版固定中文社区短帖转换为对应的英文示例，用户后来复制或编写的帖子不做此转换。

## 圈子人数

卡片、详情与成员目录采用同一个查询，显示当前账号可查看的“可见成员”数，不再将隐藏或不可联系的成员计入显示人数。初始 3 个圈子各有 Alex、Jamie、Morgan、Riley、Casey 共 5 位可见成员；Taylor 加入后，按其公开发现设置和查看者身份计算。关闭发现、关闭社区、退出或双向屏蔽后，相同查看者的卡片与目录仍保持一致。
