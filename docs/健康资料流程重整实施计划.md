# 健康资料流程重整

本轮实现用户确认的医院 PDF 同步、全文检索、集中核对、健康关注、资料共享及访问记录。沿用 React、Flask 和 SQLite，医院与接收人保持清楚的模拟边界，保留现有用户数据。

## 系统组织

| 导航 | 页面内容 |
|---|---|
| 首页 | 下一步、待核对资料、近期读数、待办摘要 |
| 健康资料 | 报告与病历、个人健康信息（基本资料、既往史、家族史、用药、过敏） |
| 健康状况 | 需要关注、指标趋势、记录明细 |
| 提醒与服务 | 我的提醒、预约演示、养老服务信息 |
| 共享与访问 | 我的授权、接收人访问、我的操作 |
| 病友交流 | 动态、圈子、好友私聊，可关闭 |
| 右上角 | 通知中心、账号与安全、使用帮助 |

## 实施与边界

1. 医院同步导入真实合成 PDF，带来源和日期，自动分类与全文提取；重复同步不重复新增。分类调整和备注不改变医院原件。
2. 全文索引按附件及页保存，与共享正文分开；支持命中片段、页码、文字阅读和原件入口。部分识别和失败明确可见并可重试。
3. 同步或上传后产生指标与健康资料候选，集中核对。未经确认不进入指标或健康史；来源可回看，冲突不覆盖较新信息。
4. 健康关注按主题合并已确认的资料和读数，展示依据与有限规则的适用范围，不生成诊断或治疗方案。
5. 共享明确选择原件、文字信息、个人健康信息及指标，固定新授权范围；不把 OCR 全文隐式加入旧授权。接收人只读，模拟访问仍执行真实权限校验。
6. 操作记录贯穿同步、分类、识别、核对、授权、访问；本人、系统整理和模拟外部人员清楚区分。
7. 社区不自动读取或发布健康资料，好友关系不开放健康资料权限。

## 验收

本计划的功能已实施，使用独立验收数据库完成同步闭环、全文与扫描件定位、核对后入档、来源回查、共享预览及撤销、双账号好友私聊，以及桌面和 390px 手机布局检查。交付演示库另行新建，保留旧演示和业务数据库。当前组织、启动命令、边界及最终回归结果见 [健康资料流程与验收说明](健康资料流程与验收说明.md)。
